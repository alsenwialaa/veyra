# Open Decisions register

Canonical proposal: v4.1. Review date: 2026-08-25.

An **Open**, **Proposed**, or **Deferred** item blocks any implementation, compatibility, privacy, module, or release claim that depends on it. “Proposed” is a working engineering direction, not acceptance. Owners and approvers are intentionally unassigned until the project names accountable people; role placeholders are not evidence.

## Decision-record requirements

Closing a decision requires: owner, approver, date, affected proposal sections/anchors/features/tools, constraints and options, explicit decision, security/privacy/commerce/accessibility consequences, migration/rollback consequences, tests, documentation, review/expiry trigger, and any superseded record.

## Current release impact

- Exact provider model ID, region, retention mode, privacy/legal basis, fallback, and quality evidence remain unresolved; provider readiness is **Unconfigured**, and all five independent Context/privacy/result-projection/Woo/snapshot certification flags are false.
- Compatibility support is untested. Proposed minima are implementation gates only.
- Retention periods, legal holds, export/erasure boundaries, and external processors require merchant/legal approval.
- Context Bundle `1.1.0` remains transient as provider content, while schema `1.5.0` durably stores a metadata-only actor-scoped source/selection manifest and schema `1.6.0` stores the bounded unresolved-reference set on Conversation Focus. Retention, source-deletion propagation, legal-hold operations, access, volume/index, live migration, backup/restore, and rollback policy remain unresolved.
- Candidate `0.1.7` retains the bounded prohibited-data redactor, strengthens recursively closed ToolResult projections, exact multi-product reference binding, and logged-in Woo actor/session checks. The checked-in Draft 2020-12 runner compiles registered schemas, but extension invariants, independent certification, projection acceptance, coherent snapshot/post-mutation freshness, and guest-to-Woo-session binding remain unresolved.
- Gateways, shipping/tax, order-amendment financial routes, branches, CRM, offline-payment rules, and every optional adapter remain undefined.
- Incident, backup/restore, SLO, evaluation, human-review, release, and waiver ownership remain unassigned.
- No optional module is certified.
- Public product naming/packaging clearance is unresolved.
